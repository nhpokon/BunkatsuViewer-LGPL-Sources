# BunkatsuViewer LGPL Source Archives

## Purpose

This repository is intended to provide corresponding source archives and related technical information for open-source components used by BunkatsuViewer.

- This is not the source repository for the BunkatsuViewer application.
- BunkatsuViewer itself is `Proprietary / All Rights Reserved`.
- General distribution of BunkatsuViewer is planned through the Microsoft Store.
- The source archives listed here are planned to be provided as GitHub Releases assets.

## Components

- Qt Community 6.11.1
- PySide6 Essentials 6.11.1
- Shiboken6 6.11.1

PySide6 Essentials and Shiboken6 are provided from the same Qt for Python source archive.

## Source Archives

- Qt: `qt-everywhere-src-6.11.1.zip`
- Qt for Python: `pyside-setup-everywhere-src-6.11.1.zip`

## Integrity

SHA-256 values identify the corresponding source archives and can be used to verify downloaded files. See [`SHA256SUMS.txt`](SHA256SUMS.txt) for the complete list.

## Releases

The source archives are planned to be provided as GitHub Releases assets. No source release has been published yet.
